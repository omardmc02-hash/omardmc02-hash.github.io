Contextualización Teórica

Diferencia Progresiva — 1° Orden
f'(x) ≈ [f(x+h) − f(x)] / h

Aproxima la derivada usando el punto actual y el siguiente. Error O(h).

PrecisiónO(h)
Diferencia Regresiva — 1° Orden
f'(x) ≈ [f(x) − f(x−h)] / h

Usa el punto actual y el anterior. Misma precisión O(h).

PrecisiónO(h)
Diferencia Centrada — 1° Orden
f'(x) ≈ [f(x+h) − f(x−h)] / (2h)

Combina puntos anterior y posterior. Error O(h²) — mucho más precisa.

PrecisiónO(h²) ★
Segunda Derivada — Centrada
f''(x) ≈ [f(x+h) − 2f(x) + f(x−h)] / h²

Aproxima curvatura. Fundamental para máximos/mínimos (2ª derivada).

PrecisiónO(h²)
Comparación Geométrica
Las tres aproximaciones convergen a la derivada real al reducir h. La centrada es la más cercana a la tangente exacta.
🔷 Regla del Trapecio
∫ ≈ (b−a)/2 · [f(a) + f(b)]

Aproxima el área bajo la curva usando trapecios. Compuesto: suma de n trapecios.

Compuesto: h/2·[f(x₀)+2f(x₁)+...+f(xₙ)]
PrecisiónO(h²)
🔶 Simpson 1/3
∫ ≈ h/3·[f(x₀)+4f(x₁)+f(x₂)]

Usa parábolas. Requiere n par. Alta precisión para funciones suaves.

Compuesto: h/3·[f₀+4f₁+2f₂+4f₃+...+fₙ]
PrecisiónO(h⁴) ★
🔸 Simpson 3/8
∫ ≈ 3h/8·[f(x₀)+3f(x₁)+3f(x₂)+f(x₃)]

Usa polinomios cúbicos. Requiere n múltiplo de 3. Precisión O(h⁴).

Compuesto: 3h/8·[f₀+3f₁+3f₂+2f₃+...+fₙ]

Costo Total Acumulado · Integrales

El costo marginal aumenta con la producción. La integral acumula estos costos marginales para obtener el costo total.

C'(x) = 4x + 200
C(x) = ∫(4x + 200)dx = 2x² + 200x + k
Con costos fijos k = 5000: C(x) = 2x² + 200x + 5000
Solución Analítica para x=50
1
Función: C'(x) = 4x + 200
2
Integrar: C(x) = 2x² + 200x + 5000
3
Evaluar: C(50) = 5000 + 10000 + 5000
4
Resultado: C(50) = $20,000 (5000 botellas)

Python 3.x · NumPy
# ============================================================\n# EC03 · Integración Numérica\n# Caso: Costo Total – Empresa de Botellas\n# ============================================================\nimport numpy as np\n\ndef Cp(x):\n return 4*x + 200\n\ndef trapecio(f, a, b, n=10):\n h = (b-a)/n\n xs = np.linspace(a, b, n+1)\n ys = f(xs)\n return h/2 * (ys[0] + 2*np.sum(ys[1:-1]) + ys[-1])\n\ndef simpson13(f, a, b, n=10):\n if n % 2 != 0: n += 1\n h = (b-a)/n\n xs = np.linspace(a, b, n+1)\n ys = f(xs)\n coef = np.ones(n+1)\n coef[1:-1:2] = 4\n coef[2:-1:2] = 2\n return h/3 * np.dot(coef, ys)\n\nif __name__ == "__main__":\n a,b=0,50\n print(f"Trapecio (n=10): {trapecio(Cp,a,b,10):.4f}")\n print(f"Simpson 1/3 (n=10): {simpson13(Cp,a,b,10):.4f}")

% EC03 - Integración Numérica en MATLAB\nfunction integracion_numerica()\n Cp=@(x) 4*x+200;\n a=0; b=50; n=10;\n h=(b-a)/n; xs=a:h:b;\n trap=h/2*(Cp(a)+2*sum(Cp(xs(2:end-1)))+Cp(b));\n simp=h/3*(Cp(a)+4*sum(Cp(xs(2:2:end-1)))+2*sum(Cp(xs(3:2:end-2)))+Cp(b));\n fprintf('Trapecio: %.4f\\n',trap);\n fprintf('Simpson 1/3: %.4f\\n',simp);\nend

Análisis

La diferencia centrada ofrece el mejor balance entre precisión (O(h²)) y costo computacional (2 evaluaciones). La segunda derivada en x=60 confirma que G''(60) = -4 < 0, verificando que es un máximo.

Análisis

Para C'(x) = 4x + 200 (función lineal), los tres métodos logran error prácticamente cero con pocos subintervalos. En funciones no lineales, Simpson 1/3 destaca por su orden O(h⁴). El costo total de producir 5000 botellas es $20,000 (incluyendo $5,000 de costos fijos).
